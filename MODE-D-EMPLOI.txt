SITE « LES EXPERTS EN PÉRIGORD » — MODE D'EMPLOI
=================================================

Le contenu du site se modifie en ligne avec Pages CMS :
https://app.pagescms.org

Plus besoin de télécharger ni d'envoyer de fichiers : on écrit, on enregistre,
et le site en ligne se met à jour tout seul en une à deux minutes.


1. PREMIÈRE CONNEXION (le propriétaire du dépôt GitHub, une seule fois)
-----------------------------------------------------------------------
  1. Allez sur https://app.pagescms.org et cliquez sur « Sign in with GitHub ».
  2. Autorisez Pages CMS et installez son application GitHub sur le dépôt
     Expert-Perigord quand c'est demandé.
  3. Ouvrez le dépôt Expert-Perigord dans Pages CMS : les rubriques du site
     apparaissent dans le menu de gauche.


2. INVITER LES AUTRES MEMBRES
-----------------------------
  Dans Pages CMS, ouvrez le dépôt, puis le menu « Collaborators »
  (Collaborateurs) et invitez chaque membre avec son adresse e-mail.
  Ils reçoivent un lien de connexion par e-mail : pas besoin de compte GitHub.


3. CE QU'ON PEUT FAIRE
----------------------
  Jeux testés     un fichier par jeu : article, verdict, poids, photos,
                  et une note sur 10 + un avis pour chacun des quatre membres.
  Festivals       un fichier par festival : dates, lieu, article, photos.
  L'équipe        les fiches des membres.
  Textes du site  présentation, piliers, histoire, événement, contact, Discord,
                  galerie et témoignages.

  Pour ajouter un jeu : « Jeux testés » > « Add an entry » (Ajouter), remplissez,
  puis « Save » (Enregistrer).
  Pour donner son avis sur un jeu : ouvrez le jeu, dépliez « L'avis des Experts »,
  remplissez votre note et votre avis, puis « Save ».

  Plusieurs membres peuvent travailler en même temps sur des jeux différents.
  Évitez seulement de modifier le MÊME jeu au même moment.


4. BON À SAVOIR
---------------
  - Le site met une à deux minutes à se mettre à jour après un enregistrement.
  - Les photos sont rangées dans le dossier images/uploads. Privilégiez des photos
    de moins de 2 Mo (une photo de téléphone réduite suffit largement).
  - Ajouter un nouveau membre à l'équipe : la fiche se crée dans « L'équipe »,
    mais pour qu'il ait sa case « Avis » sur les jeux, demandez à Claude
    d'ajouter son nom dans la configuration (.pages.yml).
  - Le fichier contenu.js est fabriqué automatiquement par GitHub :
    ne le modifiez pas à la main.


5. RÉFÉRENCEMENT (GOOGLE)
-------------------------
  - Chaque jeu testé et chaque festival a sa propre page, fabriquée
    automatiquement : jeu-experts-perigord.fr/jeux/nom-du-jeu/ et
    jeu-experts-perigord.fr/festivals/nom-du-festival/.
    L'adresse vient du nom du fichier créé par Pages CMS.
  - Le plan du site (jeu-experts-perigord.fr/sitemap.xml) se met à jour tout seul.
    Déclarez-le une fois dans Google Search Console et Bing Webmaster Tools.
  - Le « Résumé » de chaque jeu ou festival sert de description dans Google :
    soignez-le (une à deux phrases claires).
  - Pour Google, un festival est un événement : remplissez bien la date de début
    et le lieu.


6. LA LUDOTHÈQUE (SYNCHRONISÉE AVEC BOARDGAMEGEEK)
--------------------------------------------------
  La page Ludothèque regroupe les jeux marqués « Je possède » dans les collections
  BoardGameGeek des membres, sans doublon, avec leur miniature, le nombre de joueurs,
  la durée, l'âge, le poids et le nom de leurs propriétaires (« Chez Pat, Thyl »).
  Elle se met à jour toute seule chaque nuit.

  Mise en place (une seule fois) :
  1. Demander une clé d'accès à BoardGameGeek : https://boardgamegeek.com/applications
     (licence non commerciale gratuite ; l'approbation peut prendre une semaine ou plus).
     Une fois approuvée, créer un « Token » et le copier.
  2. Sur GitHub, dépôt Expert-Perigord > Settings > Secrets and variables > Actions
     > New repository secret. Nom : BGG_TOKEN ; valeur : la clé copiée.
  3. Chaque membre ouvre sa fiche dans Pages CMS (L'équipe) et remplit
     « Nom d'utilisateur BoardGameGeek » (le nom, ou l'adresse de son profil),
     puis enregistre. La synchronisation démarre aussitôt.
     Si l'association a aussi son propre compte : Textes du site > Ludothèque.

  Au quotidien :
  - Ajouter un jeu : sur BoardGameGeek, cocher « Je possède » sur sa fiche.
  - Retirer un jeu : décocher « Je possède » (sur le compte de chaque propriétaire).
  - Pour ne pas attendre la nuit : GitHub > onglet Actions > « Synchroniser la
    ludothèque » > Run workflow.
  - Les extensions ne sont pas affichées.
  - Un jeu testé par les Experts est reconnu par son nom et relié à son article.
  - Si un nom d'utilisateur est mal saisi, la synchronisation apparaît en rouge dans
    l'onglet Actions : les jeux de ce membre restent affichés jusqu'à la correction.
